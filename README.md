# Xeridian

## Setup Instructions

1. **Fork this repo** — click "Fork" at the top right of this page on GitHub.

2. **Clone your fork:**
```bash
   git clone https://github.com/<your-username>/Xeridian.git
   cd Xeridian/mobile
```

3. **Install Node.js** (if you don't have it) — download the LTS version from [nodejs.org](https://nodejs.org)

   Check it installed correctly:
```bash
   node -v
   npm -v
```

4. **Install the app's dependencies:**
```bash
   npm install
```

5. **Install Expo Go on your phone** — [iOS](https://apps.apple.com/app/expo-go/id982107779) or [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)

6. **Run the app:** — Create a account and login using 
 
```bash
   npx expo login
```
Then start of the application using

```bash
   npx expo start
```
   Scan the QR code with your phone's camera (iOS) or the Expo Go app (Android).
